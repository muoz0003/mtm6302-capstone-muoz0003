# Capstone Project

This repository contains the source code for the **Capstone Project Nasa Picture of the Day**.

## Project Overview

The **Capstone Project Nasa Picture of the Day** focuses on creating a website to demostrate the API from Nasa that shows pictures of the galaxy for each day. The mockup is focus on a Desktop, Tablet and Mobile screen sizes in the mockup folder you can find the respective pdf for each one, my intention is to make a one page scrolling website with a quick link menu that will jump to a specific part of the page instead of loading another page, There will be animations for Buttons and the about page will display how many pictures the site has displayed that particular date, also there will another section for the picture of yesterday, tomorrow and a random that users can access, finally there will be a contact form that users can use to send feedback or send messages this will be coded on JS.
